Detailed Vulnerability Findings

High Cross Site Scripting (Reflected)

CWE: CWE-79 | WASC: WASC-8

URL Affected: http://localhost:3000/api/search?q=%3Cscript%3Ealert(1)%3C%2Fscript%3E

Description: A Reflected Cross-Site Scripting (XSS) vulnerability was identified on the /api/search endpoint. The parameter q was reflected directly into the server response HTML without context-aware sanitization or entity encoding.

Attack Vector:

GET /api/search?q=<script>alert('hacked')</script> HTTP/1.1
Host: localhost:3000

Response Evidence:

<p>Không tìm thấy sinh viên với từ khóa: <b><script>alert('hacked')</script></b></p>

Remediation: Encode all user input before outputting in HTML context, use res.json() uniformly, and enforce strict input validation.

Medium X-Frame-Options Header Not Set

CWE: CWE-1021 | WASC: WASC-15

URL Affected: http://localhost:3000/api/students (All Endpoints)

Description: The response does not include the X-Frame-Options header or equivalent Content-Security-Policy: frame-ancestors directive, allowing the page to be framed by malicious websites, exposing users to Clickjacking attacks.

Remediation: Set X-Frame-Options: DENY or X-Frame-Options: SAMEORIGIN using helmet middleware in Express.

Medium Content Security Policy (CSP) Header Not Set

CWE: CWE-693

URL Affected: http://localhost:3000/api/students

Description: Content Security Policy (CSP) is an effective defense-in-depth layer against XSS, data injection, and malicious asset loading. No CSP header was detected on any API response.

Remediation: Add standard Content-Security-Policy response headers.

Low Server Leaks Information via Debug Endpoint

CWE: CWE-200 | WASC: WASC-13

URL Affected: http://localhost:3000/api/debug

Description: The debug endpoint dumps raw server runtime details including process.env, memory utilization, and uptime directly in JSON format. This reveals environment variables, internal paths, and server secrets to unauthenticated callers.

Remediation: Restrict or remove debug endpoints from production deployment configurations.

Low Server Leaks Information via "X-Powered-By" Header

CWE: CWE-200

URL Affected: All Endpoints

Description: The web framework leaks its technology stack via the X-Powered-By: Express response header.

Remediation: Disable default powered-by header: app.disable('x-powered-by').
